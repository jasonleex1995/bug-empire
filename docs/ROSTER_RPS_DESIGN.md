# 병영·디펜스·업그레이드 기획 초안 v2 (미구현)

> **원칙:** 상성·개성·업그레이드 축을 먼저 합의한다. 수치·코드는 그 다음.
> v1(`디펜스 ▷ 개미 ▷ …`)에서 한 걸음 더: **중후반 디펜스 퇴장**을 전제로 3종족 삼각형이 스스로 서게 만든다.

---

## 0. 사고의 흐름 (합의된 논리)

1. **초반**에는 디펜스가 템포를 만든다 (늦추기·밀치기).
2. **중후반**에는 디펜스가 약해지길 원한다 → 승패는 **개미 ↔ 사마귀 ↔ 풍뎅이**로 결정된다.
3. 그렇다면 성 업그레이드는 “전부 세지게”가 아니라, **내가 이기는 상대는 더 이기고 / 지는 상대에게는 구멍만 메우되 뒤집어지지 않게** 짜야 한다.
4. 디펜스는 계열 카운터 DPS가 아니라 **공용 지연 도구 + 파괴 시 반발**로 둔다.

이 문서의 목표는 수치표를 쓰는 게 아니라, 위 논리가 **모순 없이 맞물리는지** 검토하는 것이다.

---

## 1. 중후반 삼각형 (본체)

```
개미  ▷  사마귀  ▷  풍뎅이  ▷  개미
```

| 관계 | 이기는 쪽의 “무기” | 지는 쪽이 업으로 메우면 안 되는 구멍 |
| --- | --- | --- |
| **개미 → 사마귀** | 물량 + **독**(방어 무시 DoT) + 공속으로 독/타수 가속 | 사마귀가 독까지 무시하면 삼각형 붕괴 |
| **사마귀 → 풍뎅이** | **방어 관통**(갑옷 무효) + 리치 | 풍뎅이가 관통 면역이 되면 붕괴 |
| **풍뎅이 → 개미** | **방어로 직딜 흡수** + **독 저항**으로 DoT를 짧게 | 개미가 풍뎅이에게도 독이 그대로면 붕괴 |

핵심: 각 계열의 업그레이드는 **자기 무기를 키우고**, 약점 축은 “덜 아프게”만 하지 **카운터를 무효화하지 않는다**.

---

## 2. 계열 컨셉 (한 줄)

| 계열 | 컨셉 | 비유 |
| --- | --- | --- |
| **개미** | 독 + 물량. 맞춰 죽어도 독이 남고, 숫자가 압박한다 | 저글링/메카닉 러시 + 독 |
| **풍뎅이** | **저항하는 탱**. 안 죽고, 디버프를 짧게 만들고, 천천히 밀어붙인다 | 울트라/토르 느낌의 “버티는 돌파” (공성 올인은 2순위) |
| **사마귀** | **관통 유리캐논**. 갑옷을 무시하고 두드리지만, 맞아 죽는다 | 히드라/귀족 같은 정면 화력 |

풍뎅이를 “공성 특화”보다 **저항 탱**으로 두는 편이,  
`풍뎅이 → 개미(독)` 각을 디펜스 없이도 설명하기 쉽다.

## 3. 성 업그레이드 재설계 (안)

슬롯은 **계열당 2개 핵심**을 먼저 고정한다. (지금은 3슬롯이지만, 기획상 2축이 본체. 3번째가 필요하면 “약한 보조”만.)

### 3.1 개미 — 독의 가속 / 줄 유지 (**확정**)

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **공격속도** | 타수↑ → 독 재적용·직딜 누적↑ | 사마귀(방높·체낮)를 **독 틱/타수**로 녹이는 주 무기 |
| **체력** | 줄이 안 끊김 | 사마귀 한방·풍뎅이 충돌에 전멸하지 않게. “양 많은 저글링” 유지 |

넣지 않는 것: 공격력 스케일(풍뎅이 카운터 붕괴), 이속은 주축 아님.

### 3.2 풍뎅이 — 방어 + 저항 (**확정 방향**)

사마귀가 “약점(갑옷)을 찌른다”는 fantasies가 성립하려면 풍뎅이 쪽에 **방어 스케일**이 있어야 한다.  
따라서 2축은 **방어 + 저항** (체력 업은 주축에서 제외, 병종 베이스 HP로만 구분).

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **방어력** | 개미 직딜을 1에 가깝게 | `풍뎅이 → 개미` + 사마귀가 찌를 **약점 스탯** |
| **저항** | 독 지속↓, 둔화 시간↓ 등 | 개미 독·공용 디펜스 늦추기를 짧게 끊음 |

**저항의 정의:**

- 독: 지속 시간 단축(예: 5s → 업에 따라 2s까지). DPS 자체보다 “빨리 끊김”.
- 둔화/밀치기: 지속·거리 감소.
- **관통은 저항으로 막지 않음.**

공성 할증 같은 “건물만 더 때리기” 특수 보너스는 **쓰지 않음**.  
풍뎅이 차별화는 병종 베이스 스탯(체력·방어·속도) + 성 업(방어·저항)으로만.

### 3.3 사마귀 — 관통 + 방어 (**확정 방향**)

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **방어 관통** | 방어를 깎아 적용하는 양(아래 공식). 공격력보다 **효율 좋게** 성장 | `사마귀 → 풍뎅이` |
| **방어력** | 개미 직딜에 덜 녹음 | 약점 메우기. **독(방관 DoT)은 그대로**라 개미 카운터 유지 |

#### 관통 공식 (합의된 이해)

관통은 **추가 피해가 아니다**. 상대 방어력 중 일부를 무시할 뿐이다.

```
적용방어 = max(0, 대상방어 - 관통)
최종피해 = max(1, 공격력 - 적용방어)
```

예시:

| 공격 | 관통 | 대상 방어 | 적용 방어 | 피해 |
| --- | --- | --- | --- | --- |
| 10 | 15 | 2 | 0 | **10** (방어 2를 전부 무시. 15를 빼서 -5가 되지 않음) |
| 10 | 15 | 20 | 5 | **5** |
| 10 | 0 | 2 | 2 | **8** |

“공격 10일 때 관통 15” = 사마귀는 **공격력 대비 관통 스탯이 더 후하게** 잡힌다(유닛 베이스·업 성장비).  
풍뎅이 방어를 올려도 사마귀 관통 업이 따라가면 갑옷이 녹고, 개미처럼 공격만 올리는 쪽보다 대갑옷 효율이 좋다.

### 3.4 업그레이드 ↔ 상성 체크리스트

업을 풀로 찍어도 뒤집히면 안 되는 것:

| 질문 | 합격 조건 |
| --- | --- |
| 개미 풀업 vs 풍뎅이 풀업 | 풍뎅이가 여전히 유리 (방+독저항) |
| 풍뎅이 풀업 vs 사마귀 풀업 | 사마귀가 여전히 유리 (관통이 방어를 상쇄) |
| 사마귀 풀업 vs 개미 풀업 | 개미가 여전히 유리 (독+물량+공속; 사마귀 방으로는 독 못 막음) |

“약점 메우기” 업은 **패배 시간을 늘릴 뿐**, 승자를 바꾸면 실패다.

## 4. 병영 유닛 (역할만, 수치 X)

### 개미
| 병종 | 역할 |
| --- | --- |
| 검정개미 | 근거리 물량. 독 없거나 매우 약함 |
| 불개미 | 근거리 + **독** |
| 산성개미 | 중거리 + **독** |

독: 병사만, 구조물 불가, 방어 무시 DoT. 풍뎅이에게는 저항으로 짧게.

### 풍뎅이
| 병종 | 역할 |
| --- | --- |
| 코뿔소풍뎅이 | 전열. (후보) 둔화 저항 체감 / 범위 엄호 |
| 장수풍뎅이 | 중열 돌파. 별도 공성 보너스 없음 |
| 사슴벌레 | 후반 고체력 (2종만 쓸지도 논의) |

### 사마귀
| 병종 | 역할 |
| --- | --- |
| 좀사마귀 | 값싼 리치 + 관통 |
| 왕사마귀 | 강한 리치 + 관통 |

전원 관통. 독과 역할이 안 겹침.

## 5. 디펜스 — 공용 “늦추기” + 파괴 반발

계열 특화 저격탑은 **쓰지 않는 방향**으로 선회한다.  
이유: 중후반에 디펜스가 약해지길 원하면, 타워가 “상성 카드”가 되면 후반에도 필수 빌드가 되기 쉽다.

### 5.1 역할
디펜스 = **시간을 산다**. 딜로 이기지 않는다.

| 모듈 (가칭) | 효과 | 누구한테 상대적으로 아픈가 |
| --- | --- | --- |
| 벽 | HP만. 길막 | 공성·시간이 필요한 쪽(풍뎅이 줄)에게 세금 |
| 둔화 장판 | 딜 없거나 극소. 이속↓ | **머리 수 많은 개미**가 체감 큼 |
| 돌풍 | 딜 없음. 짧은 밀치기 + 쿨 | 돌파 리듬을 끊음. 풍뎅이도 짜증, 만능 아님 |

후반에 유닛 스탯이 커지면 같은 둔화·밀치기의 **상대 가치**가 떨어져, 자연히 디펜스 비중이 줄어든다. (의도)

### 5.2 파괴 반발 (**확정: 모든 모듈, 파편 + 둔화**)

**디펜스만이 아니라** 농장·병영·디펜스 등 **모듈이 파괴될 때마다** 공통으로:

1. **파편 피해** (약하게, 업으로 안 커지거나 거의 안 커짐)
2. **짧은 둔화**

이유: 무너지는 구조물의 공통 연출·비용. “부숴도 한 대 맞고 잠깐 느려진다.”  
둔화는 짧게, 파편은 세금 수준이라 연속 돌파 CC 과다 / 공성 불가를 피한다.  
성(캐슬) 자체는 모듈이 아니므로 반발 대상 아님(별도 규칙).

## 6. 초반 vs 중후반 정리

| 시기 | 무엇이 게임을 결정하나 |
| --- | --- |
| 초반 | 병영 타이밍 + **공용 디펜스(늦추기)** + 파괴 반발 |
| 중후반 | **독 vs 저항 vs 관통** + 성 업 2축. 디펜스는 보조 세금 |

디펜스가 삼각형 **밖**에 있는 것이 맞다.  
(v1의 `디펜스 ▷ 개미 ▷ … ▷ 디펜스` 고리는 “초반 감각”으로는 남아도, **후반 밸런스 방정식에는 넣지 않는다**.)

## 7. 확정 / 남은 질문

### 확정
| 항목 | 결정 |
| --- | --- |
| 개미 2축 | **공속 + 체력** |
| 풍뎅이 2축 | **방어 + 저항** (체력은 병종 베이스) |
| 사마귀 2축 | **관통 + 방어** |
| 사마귀 관통 | `적용방어 = max(0, 방어 - 관통)`; 오버피어스 추가딜 없음; 관통은 공격보다 효율 좋게 |
| 장수 “공성 보너스” | **없음** (건물 추가 피해 특수기 불필요. ※예전에 말한 건 ‘장수풍뎅이가 구조물에 더 아픈 딜’ 뜻이였고, 디펜스 유지 시간 혜택이 아님) |
| 파괴 반발 | **모든 모듈** 파괴 시 **파편 + 짧은 둔화** (성에만 해당 없음) |

### 아직 열려 있음
1. ~~병종 수~~ → **확정: 개미 3 / 풍뎅이 2 / 사마귀 2**
2. 관통 성장: 베이스 고비율(~×1.5) + 성 업 +4/단계 (구현)
3. 코뿔소 범위 엄호 → **1차 미포함** (보류)
### 7.1 병종 수 권고 (개미 3 · 풍뎅이 2 · 사마귀 2)

느낌과 후반 삼각형이 맞으려면 **숫자(카드 수)로도 가격대**를 나누는 게 좋다.

| 계열 | 병종 수 | 테크 느낌 | 구성 스케치 |
| --- | --- | --- | --- |
| **개미** | **3** | 저렴·분기 많은 러시/메카닉 | 검정(근거리 물량) → 불(근거리+독) → 산성(중거리+독) |
| **풍뎅이** | **2** | 비싼 탱 테크 | 코뿔소(전열·저항 체감) + 장수(돌파). 사슴은 1차에서 빼도 됨 |
| **사마귀** | **2** | 비싼 관통 테크 | 좀(값싼 리치 관통) + 왕(강한 리치 관통) |

**왜 이 분할이 맞는지**

1. **개미 = 카드가 곧 선택지.** 독 라인이 “언제 독을 여나 / 원거리를 여나”라서 3단이 자연스럽고, 저글링·히드라·팩 같은 **값싼 계단** 느낌이 난다.
2. **풍뎅이·사마귀 = 카드가 곧 투자.** 방+저항 / 관통+방어는 성 업이 본체라, 병종을 3개로 늘리면 “스탯만 다른 비싼 유닛”가 되기 쉽다. **2장이면 각각이 역할 문장 하나**를 가질 수 있다.
3. **체감 가격은 병종 수 + 병영비·해금·생산주기로.** 개미 병영은 싸고 자주 나오고, 풍뎅이·사마귀 병영은 비싸고 드물게 — 같은 T1이라도 “저렴 테크 vs 고급 테크”가 갈린다.
4. **UI·해금 부담.** 3+2+2=7종은 지금 8~9종보다 읽기 쉽고, 후반 삼각형 검증도 단순하다.

**대안 (비추천이지만 가능)**

- 개미 3 / 풍뎅이 3 / 사마귀 2: 풍뎅이에 사슴을 후반 울트라로 둘 때. 다만 1차는 저항·방어 업만으로도 후반이 커져서 **사슴은 2차 후보**.
- 전원 3종: 대칭은 예쁘지만, 비싼 테크 느낌이 약해지고 밸런스 축이 늘어남.

**1차 확정 (구현 반영):** 개미 3 · 풍뎅이 2 · 사마귀 2. 사슴·유령은 보류.
