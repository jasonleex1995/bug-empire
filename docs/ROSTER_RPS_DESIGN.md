# 병영·디펜스·업그레이드 기획 초안 v2 (미구현)

> **원칙:** 상성·개성·업그레이드 축을 먼저 합의한다. 수치·코드는 그 다음.
> v1(`디펜스 ▷ 개미 ▷ …`)에서 한 걸음 더: **중후반 디펜스 퇴장**을 전제로 3종족 삼각형이 스스로 서게 만든다.

---

## 0. 사고의 흐름 (합의된 논리)

1. **초반**에는 디펜스가 템포를 만든다 (늦추기·밀치기).
2. **중후반**에는 디펜스가 약해지길 원한다 → 승패는 **개미 ↔ 사마귀 ↔ 풍뎅이**로 결정된다.
3. 그렇다면 성 업그레이드는 “전부 세지게”가 아니라, **내가 이기는 상대는 더 이기고 / 지는 상대에게는 구멍만 메우되 뒤집어지지 않게** 짜야 한다.
4. 디펜스는 계열 카운터 DPS가 아니라 **공용 지연 도구 + 파괴 시 반발**로 둔다.

이 문서의 목표는 수치표를 쓰는 게 아니라, 위 논리가 **모순 없이 맞물리는지** 검토하는 것이다.

---

## 1. 중후반 삼각형 (본체)

```
개미  ▷  사마귀  ▷  풍뎅이  ▷  개미
```

| 관계 | 이기는 쪽의 “무기” | 지는 쪽이 업으로 메우면 안 되는 구멍 |
| --- | --- | --- |
| **개미 → 사마귀** | 물량 + **독**(방어 무시 DoT) + 공속으로 독/타수 가속 | 사마귀가 독까지 무시하면 삼각형 붕괴 |
| **사마귀 → 풍뎅이** | **방어 관통**(갑옷 무효) + 리치 | 풍뎅이가 관통 면역이 되면 붕괴 |
| **풍뎅이 → 개미** | **체력·방어로 직딜 흡수** + **독 저항**으로 DoT 무력화 | 개미가 풍뎅이에게도 독이 그대로면 붕괴 |

핵심: 각 계열의 업그레이드는 **자기 무기를 키우고**, 약점 축은 “덜 아프게”만 하지 **카운터를 무효화하지 않는다**.

---

## 2. 계열 컨셉 (한 줄)

| 계열 | 컨셉 | 비유 |
| --- | --- | --- |
| **개미** | 독 + 물량. 맞춰 죽어도 독이 남고, 숫자가 압박한다 | 저글링/메카닉 러시 + 독 |
| **풍뎅이** | **저항하는 탱**. 안 죽고, 디버프를 짧게 만들고, 천천히 밀어붙인다 | 울트라/토르 느낌의 “버티는 돌파” (공성 올인은 2순위) |
| **사마귀** | **관통 유리캐논**. 갑옷을 무시하고 두드리지만, 맞아 죽는다 | 히드라/귀족 같은 정면 화력 |

풍뎅이를 “공성 특화”보다 **저항 탱**으로 두는 편이,  
`풍뎅이 → 개미(독)` 각을 디펜스 없이도 설명하기 쉽다.

## 3. 성 업그레이드 재설계 (안)

슬롯은 **계열당 2개 핵심**을 먼저 고정한다. (지금은 3슬롯이지만, 기획상 2축이 본체. 3번째가 필요하면 “약한 보조”만.)

### 3.1 개미 — 독의 가속 / 줄 유지

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **공격속도** | 타수↑ → 독 재적용·직딜 누적↑ | 사마귀(방높·체낮)를 **독 틱/타수**로 녹이는 주 무기 |
| **체력** | 줄이 안 끊김 | 사마귀 한방·풍뎅이 충돌에 전멸하지 않게. “양 많은 저글링” 유지 |

넣지 않는 것(의도):

- **공격력 스케일** — 풍뎅이 갑옷을 숫자로 뚫어 버리면 `풍뎅이 → 개미`가 사라짐.
- **방어력 스케일(주축)** — 넣더라도 약하게. 사마귀 직딜을 너무 버티면 개미가 만능이 됨.

이동속도는 **체력의 대체/보조 후보**다.

- 체력 = “맞아도 남는다”
- 이속 = “풍뎅이 줄에 덜 묶이고 사거리·독 위치를 잡는다”  
1차 추천은 **공속 + 체력**. 이속은 3번째 약한 보조로만.

### 3.2 풍뎅이 — 버티기 / 저항

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **방어력** | 개미 직딜을 1에 가깝게 | `풍뎅이 → 개미`의 본체 |
| **체력** | 사마귀 관통 몇 대를 더 버팀 | 완전히 안 죽으면 안 되고, “조금 더 버틴다” 수준 |
| **저항 (추천 주축 후보)** | 독 지속↓, 둔화 시간↓ 등 | 개미의 독·디펜스의 늦추기를 **짧게 끊어** 돌파 |

**저항의 정의 (제안):**

- 독: `남은 독 시간 × 감소` 또는 `독 지속 상한 단축` (예: 5s → 업당 짧게). **독 DPS 자체는 안 깎아도 됨** — “빨리 끊김”이 풍뎅이 맛.
- 둔화/밀치기: 지속·거리 감소.
- 관통은 **저항으로 막지 않음** (사마귀 카운터 보존).

공성 할증은 **병종 고유 특성**(장수풍뎅이)으로 두고, 성 업 주축에서는 빼도 된다.  
→ 풍뎅이 정체성 = “안 죽이고 디버프를 씹는 돌파”, 공성은 그 위의 양념.

### 3.3 사마귀 — 관통 / 생존 구멍 메우기

| 축 | 효과 방향 | 왜 이 축인가 |
| --- | --- | --- |
| **방어 관통** | 고정 관통량↑ 또는 “방어 무시율↑” | `사마귀 → 풍뎅이`의 본체. **공격력 대신** 이 축을 키운다 |
| **방어력** | 개미 직딜에 덜 녹음 | 약점을 “덜 아프게”. **독은 여전히 방관 DoT**라 개미 카운터는 유지 |

넣지 않는 것:

- 체력 왕창 — 독이 안 아프면 개미가 사마귀를 못 이김.
- 독 저항 — 개미 무기 박탈.

공격속도는 관통 축의 보조로 가능하나, 1차는 **관통 + 방어**가 논리가 더 맑다.

### 3.4 업그레이드 ↔ 상성 체크리스트

업을 풀로 찍어도 뒤집히면 안 되는 것:

| 질문 | 합격 조건 |
| --- | --- |
| 개미 풀업 vs 풍뎅이 풀업 | 풍뎅이가 여전히 유리 (방+체+독저항) |
| 풍뎅이 풀업 vs 사마귀 풀업 | 사마귀가 여전히 유리 (관통) |
| 사마귀 풀업 vs 개미 풀업 | 개미가 여전히 유리 (독+물량+공속) |

“약점 메우기” 업은 **패배 시간을 늘릴 뿐**, 승자를 바꾸면 실패다.

## 4. 병영 유닛 (역할만, 수치 X)

### 개미
| 병종 | 역할 |
| --- | --- |
| 검정개미 | 근거리 물량. 독 없거나 매우 약함 |
| 불개미 | 근거리 + **독** |
| 산성개미 | 중거리 + **독** |

독: 병사만, 구조물 불가, 방어 무시 DoT. 풍뎅이에게는 저항으로 짧게.

### 풍뎅이
| 병종 | 역할 |
| --- | --- |
| 코뿔소풍뎅이 | 전열. 둔화 저항 / 범위 엄호(후보) |
| 장수풍뎅이 | 돌파. (선택) 공성 보너스 — **정체성의 핵심은 아님** |
| 사슴벌레 | 후반 고체력 저항 탱 (2종만 쓸지도 논의) |

### 사마귀
| 병종 | 역할 |
| --- | --- |
| 좀사마귀 | 값싼 리치 + 관통 |
| 왕사마귀 | 강한 리치 + 관통 |

전원 관통. 독과 역할이 안 겹침.

## 5. 디펜스 — 공용 “늦추기” + 파괴 반발

계열 특화 저격탑은 **쓰지 않는 방향**으로 선회한다.  
이유: 중후반에 디펜스가 약해지길 원하면, 타워가 “상성 카드”가 되면 후반에도 필수 빌드가 되기 쉽다.

### 5.1 역할
디펜스 = **시간을 산다**. 딜로 이기지 않는다.

| 모듈 (가칭) | 효과 | 누구한테 상대적으로 아픈가 |
| --- | --- | --- |
| 벽 | HP만. 길막 | 공성·시간이 필요한 쪽(풍뎅이 줄)에게 세금 |
| 둔화 장판 | 딜 없거나 극소. 이속↓ | **머리 수 많은 개미**가 체감 큼 |
| 돌풍 | 딜 없음. 짧은 밀치기 + 쿨 | 돌파 리듬을 끊음. 풍뎅이도 짜증, 만능 아님 |

후반에 유닛 스탯이 커지면 같은 둔화·밀치기의 **상대 가치**가 떨어져, 자연히 디펜스 비중이 줄어든다. (의도)

### 5.2 파괴 반발 (Death Backlash)

문제: 타워가 딜이 없으면 “그냥 부수면 이득”만 남는다.  
처방: **파괴되는 순간** 레인에 반발.

| 안 | 내용 | 장점 | 리스크 |
| --- | --- | --- | --- |
| A. 파편 피해 | 파괴 지점 근처 적 병사에게 고정/비율 피해 | 돌파 비용이 생김 | 수치 과다 시 공성 불가 |
| B. 최후 둔화 | 짧은 강한 둔화/정지 | 딜 철학과 일치 | 연속 파괴 시 CC 과다 |
| C. 가스/미네랄 세금 | 파괴한 쪽에 자원 페널티 또는 수비측에 보상 | 전투 말고 경제로 반발 | 체감이 약할 수 있음 |
| **A+B 혼합 (추천)** | 작은 파편 피해 + 짧은 둔화 | “부숴도 한 대 맞는다” | 둘 다 약하게 |

규칙 스케치:

- 반발은 **그 레인의 적 병사**만.
- 성·병영 자체는 별도(또는 병영만 약한 반발).
- 반발은 업그레이드로 안 커지게(또는 거의 안 커지게) → 후반에도 “짜증 세금” 수준.

이렇게 하면 디펜스는:

- 초반: 늦추기 가치가 큼  
- 중후반: 늦추기 상대가치↓ + 반발은 고정 세금 → **없어도 되지만, 있으면 돌파가 조금 비싸짐**

계열 상성 카드가 아니므로, 후반 우선순위는 다시 3종족 삼각형으로 돌아간다.

## 6. 초반 vs 중후반 정리

| 시기 | 무엇이 게임을 결정하나 |
| --- | --- |
| 초반 | 병영 타이밍 + **공용 디펜스(늦추기)** + 파괴 반발 |
| 중후반 | **독 vs 저항 vs 관통** + 성 업 2축. 디펜스는 보조 세금 |

디펜스가 삼각형 **밖**에 있는 것이 맞다.  
(v1의 `디펜스 ▷ 개미 ▷ … ▷ 디펜스` 고리는 “초반 감각”으로는 남아도, **후반 밸런스 방정식에는 넣지 않는다**.)

## 7. 검토 포인트 / 열린 선택

1. **풍뎅이 2축:** `방어+체력` vs `방어+저항` vs `체력+저항`?  
   - 추천: **체력 + 저항**, 방어는 병종 베이스+소량 업 또는 3번째 약축.  
   - 이유: “독 끊기”가 `풍뎅이→개미`를 디펜스 없이 설명하고, 체력은 사마귀에게 한 타이 더 버팀.
2. **사마귀 관통**을 “완전 무시” vs “관통 +N”으로 할지.  
   - 완전 무시가 개성은 강하고, +N이 튜닝은 쉬움.
3. **개미 2축:** 공속+체력 확정할지, 공속+이속으로 “안 맞기” 빌드를 살릴지.
4. **파괴 반발** A/B/C 중 무엇으로 1차 갈지. (추천 A+B 약하게)
5. 장수풍뎅이 공성 보너스를 유지할지, 풍뎅이 전체에서 공성 맛을 줄일지.
