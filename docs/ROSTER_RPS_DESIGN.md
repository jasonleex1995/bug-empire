# 병영·디펜스 기획 초안 (미구현)

> **원칙:** 가위바위보 상성과 종족 개성을 먼저 고정한다. 수치·코드·토너먼트는 이 문서가 합의된 뒤에 맞춘다.
> 아래는 예시가 아니라 **논의용 설계안**이다. 확정 전 구현하지 않는다.

---

## 1. 목표

1. 세 계열(개미 / 풍뎅이 / 사마귀)이 **업그레이드 후에도** 서로 다른 이유로 강하다.
2. 병영 유닛만의 삼각형이 아니라 **디펜스까지 포함한 순환**이 있다.
3. 각 병종은 “스탯만 다른 같은 유닛”이 아니라 **한 문장으로 설명되는 역할**을 가진다.
4. 실제 곤충 특성을 역할의 핑계로 쓴다(독, 뿔·턱, 리치·매복 등).

---

## 2. 순환 상성 (디펜스 포함)

의도하는 큰 고리:

```
디펜스  ▷  개미  ▷  사마귀  ▷  풍뎅이  ▷  디펜스
```

| 관계 | 왜 이기는가 (메커니즘 방향) |
| --- | --- |
| **디펜스 > 개미** | 물량은 범위·둔화·밀치기에 녹는다. 개미는 체력 스케일이 약해 칩뎀이 쌓인다. |
| **개미 > 사마귀** | 숫자 + **독(방어 무시 DoT)** 이 유리몸·고방어 사마귀를 녹인다. |
| **사마귀 > 풍뎅이** | **방어 관통** / 리치로 갑옷 탱커를 찢는다. |
| **풍뎅이 > 디펜스** | 공성 특화 + 둔화 저항 + (코뿔소) 범위 엄호로 타워 라인을 밀어낸다. |

소프트 배율(×1.2류)은 **보조**일 뿐, 상성의 본체는 위 메커니즘이어야 한다.

### 업그레이드 후에도 한쪽으로 안 쏠리게

| 걱정 | 기획 대응 |
| --- | --- |
| 개미가 공속·이속만 올리고 디펜스를 무시 | 개미에 **체력 업 없음**. 디펜스 피해 하한 1 유지 → 물량이 타워 앞에 서 있으면 계속 깎임. |
| 풍뎅이 방어 업으로 개미 직딜이 1만 들어감 | 개미의 카운터는 **독**(방어 무시). 직딜이 막혀도 DoT로 숨통. 대신 독은 풍뎅이에게 약함(아래). |
| 후반 디펜스가 무의미 | 디펜스는 “초반 게이트”가 아니라 **특정 계열 카운터 도구**. 계열 특화 타워(§5)로 후반에도 선택지가 남게. |
| 사마귀만 올리면 풍뎅이 소멸 | 사마귀는 **방어 업 없음** + 낮은 HP → 개미 독·물량에 약점 유지. |

## 3. 계열 정체성 + 성 업그레이드

| 계열 | 한 줄 정체성 | 성 업그레이드 3종 (안) |
| --- | --- | --- |
| **개미** | 무난한 범용 + **독**이라는 특수 자원 | 공격속도 / 이동속도 / 방어력 |
| **풍뎅이** | 느린 탱커 + **구조물 파괴** | 공격력 / 방어력 / 체력 |
| **사마귀** | 유리 캐논 + **방어 관통** | 공격력 / 공격속도 / 이동속도 |

의도적으로:

- 개미는 **공격력 스케일 없음** → 물량·독·공속으로 싸운다.
- 사마귀는 **방어 스케일 없음** → 맞아 죽는 맛이 남고, 독·물량의 먹잇감이 된다.
- 풍뎅이만 **체력 스케일** → “안 죽는 돌파” 정체성.

## 4. 병영 유닛 설계안

숫자는 아직 정하지 않는다. **역할만** 고정 후보로 둔다.

### 4.1 개미 — 독 라인

| 병종 | 역할 (SC 비유) | 곤충 핑계 | 핵심 규칙 |
| --- | --- | --- | --- |
| **검정개미** | 저글링 | 일개미 돌격 | 완전 근거리, 독 없음(또는 매우 약함), 최다 생산 |
| **불개미** | 독 붙은 근거리 강화 | 불개미 독침 | 완전 근거리, **독 DoT**, 검정개미보다 단단/세다 |
| **산성개미** | 히드라 | 개미산 분사 | **중거리**, 독 DoT (또는 직딜+약한 독) |

**독 규칙 (제안):**

- 병사에게만 적용. **모듈·성에는 안 묻음** (공성 상성을 독이 훔치지 않게).
- DoT는 **방어력 무시**.
- 계열 배율로 상성: 예) 사마귀 ×1.3~1.4, 풍뎅이 ×0.4~0.6, 개미 ×1.0.
  - 이유: 풍뎅이는 체력이 높아 틱이 아프지 않고, 사마귀는 유리몸이라 틱이 치명적.
- 스택: 갱신(duration refresh) + 강한 DPS 유지. 복잡 스택은 후순위.

**열린 선택:**

- A) 불개미만 독 / 산성은 원거리 직딜만  
- B) 불·산성 둘 다 독 (강도·사거리로만 구분) ← 추천  
- C) 산성만 독, 불개미는 근거리 스플래시(파이어뱃) — 독 개성이 흐려짐

### 4.2 풍뎅이 — 탱·공성 라인 (뿔·턱 실루엣)

| 병종 | 역할 | 핵심 규칙 |
| --- | --- | --- |
| **코뿔소풍뎅이** | 돌격 방패 | **둔화 면역**, **범위 엄호**(뒤 아군은 적 스플래시·디펜스 AoE에 안 맞음) |
| **장수풍뎅이** | 공성 돌파 | 모듈·성 피해 **할증**(공성 배율 높음) |
| **사슴벌레** (T3 후보) | 울트라급 돌파 | 최고 체력·방어, 공성도 강함. 스플래시보다 “안 죽음”에 투자 |

실루엣: 뿔/턱 달린 갑옷형으로 통일 (꽃무지·무당벌레는 제외).

**열린 선택:**

- 풍뎅이 2종만 (코뿔소 + 장수) vs 3종(+사슴). 2종이면 UI·해금이 단순, 3종이면 후반 카드가 남음.
- 범위 엄호 범위를 “같은 레인 + 가드보다 뒤”로만 할지, 주 대상이 코뿔소일 때만 할지.

### 4.3 사마귀 — 관통 라인

| 병종 | 역할 후보 | 핵심 규칙 |
| --- | --- | --- |
| **좀사마귀** | 값싼 리치 관통 | 사거리 > 근거리, **방어 관통**, 낮은 HP |
| **왕사마귀** | 중화력 리치 관통 | 더 긴 리치·더 큰 한방, 여전히 유리몸 |
| **(후보) 유령사마귀** | 저격/특수 | 더 긴 원거리 단타 관통, 또는 적중 둔화. 독과 역할이 안 겹치게 **직딜 관통**만 |

전원 관통이 기본 개성. 개미에게 독을, 사마귀에게 관통을 줘 **특수기가 겹치지 않게**.

**좀/왕을 가르는 축 (택1 또는 조합):**

1. 사거리 (짧음 vs 김)  
2. 생산비·주기 (물량형 vs 소수 정예)  
3. 대구조물 페널티 강도 (둘 다 약함 vs 왕만 조금 덜 약함)

## 5. 디펜스 타워 기획

지금은 “공용 3종(벽·독버섯·포탑)”이 계열 카운터 도구로 약하다.  
**방향 두 가지**를 놓고 고른다.

### 방향 A — 공용 슬롯 + 역할만 RPS에 맞춤 (단순)

| 타워 | 주 카운터 | 역할 |
| --- | --- | --- |
| 가시덤불(벽) | 시간벌기 | 모든 계열 공통. 풍뎅이 공성에 약함 |
| 독/둔화 AoE | **개미** | 약한 지속딜 + 둔화 → 물량 녹이기 |
| 단타 포탑 | 빈집 견제 | 사마귀·소수 유닛에 준수, 풍뎅이에는 약함 |

장점: UI·해금 단순.  
단점: “계열마다 특화 타워” 맛이 약함.

### 방향 B — 계열 특화 디펜스 (개성 강함, 추천안)

플레이어가 **상대 계열을 보고** 타워를 고른다. 비용·설치 수는 공통 제한.

| 타워 (가칭) | 특화 대상 | 효과 스케치 | 곤충/연출 |
| --- | --- | --- | --- |
| **이슬/독안개 탑** | 개미 | 약한 광역 + **강한 둔화**. 풍뎅이·사마귀에는 딜 미미 | 개미를 끈끈이에 묶음 |
| **돌풍/진동 탑** | 풍뎅이 | 딜 거의 없음. 주기적으로 전방 적을 **짧게 뒤로 밀침**(돌파 리듬 방해). 코뿔소 둔화면역과 별개 축 | 날개짓·바람 |
| **가시덫/채찍 탑** | 사마귀 | **단타 고딜** 또는 “유리몸 추가 피해”. 범위 없음. 물량에는 비효율 | 사마귀 리치를 되받아침 |
| **가시덤불** | 공용 | 순수 벽. 풍뎅이 공성의 먹이 | — |

상성 읽기:

- 개미 러시 → 독안개  
- 풍뎅이 돌파 → 돌풍으로 리듬 끊기 (+ 벽)  
- 사마귀 관통 라인 → 가시덫으로 저격  

**돌풍 설계 주의:** “永久 CC”가 되면 풍뎅이가 死滅.  
→ 쿨이 길고, 밀치는 거리가 짧고, **같은 대상 연속 면역 짧게** 두는 식으로 게이트만 담당.

### 방향 C — 하이브리드

공용 벽 1 + 특화 타워 3을 카드로 두되, **레인당 특화 타워 1개** 제한.

## 6. 병영 ↔ 디펜스 맞물림 (플레이 루프)

1. 상대가 **개미**를 찍으면 → 독안개/둔화 디펜스, 본인은 풍뎅이 공성으로 타워 라인 무시 압박.  
2. 상대가 **풍뎅이**를 찍으면 → 돌풍으로 템포 끊기 + **사마귀 관통** 병영.  
3. 상대가 **사마귀**를 찍으면 → **개미 독 라인** 병영 + (필요 시) 가시덫.  
4. 빈 레인 도배 → 공용 벽·단타로 시간 벌고 병영 따라잡기.

성 업그레이드는 “이긴 싸움을 눈덩이”로 만들되, **빠진 축(개미 체력 / 사마귀 방어)** 때문에 카운터 계열이 끝까지 숨 쉰다.

---

## 7. 아직 넣지 않는 것 (후순위)

의도적으로 1차 로스터에서 빼 둔 역할:

- 메딕/흡혈 (회복)  
- 자폭  
- 매혹/정신지배  
- 원거리 광역 누커 (하이템플러급) — 독안개 디펜스·산성 독과 역할 충돌 여부 확인 후

2차에서 개미/풍뎅이/사마귀 중 **구멍이 남은 계열**에만 붙인다.

3. 디펜스 **방향 A / B / C**?  
4. 독은 불+산성 둘 다(B)로 갈지?  
5. 돌풍 밀치기를 1차에 넣을지, 1차는 둔화 AoE+벽+단타만 두고 2차에 밀치기?
